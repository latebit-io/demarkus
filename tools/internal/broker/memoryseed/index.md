# Memory

This is your personal demarkus memory: a private, versioned markdown memory store. Agents connected to it recall context here before starting work and record what matters as they go. This hub is the map; keep it current as documents are added.

## Layout

- `/journal/<YYYY-MM-DD>.md`: dated session notes, one document per day
- `/debugging.md`: lessons from bugs and investigations
- `/patterns.md`: patterns and conventions worth reusing
- `/adr/<NNNN>-<title>.md`: one decision record per significant decision
- `/plans/<name>.md`: plan documents for larger pieces of work
- `/thoughts.md`: reflections and ideas

The full layout contract lives at `/.well-known/demarkus/template.md`, and the write policy at `/.well-known/demarkus/policy.md`.
